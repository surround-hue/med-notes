一、体液与渗透压的生理基础 Body fluid basics

体液（占体重约 60%，成年男性） ├── 细胞内液 ICF（40%）—— 阳离子以 K⁺ 为主，阴离子以 HPO₄²⁻ 为主 └── 细胞外液 ECF（20%）—— 阳离子以 Na⁺ 为主，阴离子以 Cl⁻ 为主 ├── 组织间液（15%） └── 血浆（5%）
项目数值 / 要点
血浆渗透压正常值280–310 mmol/L（mOsm/L）
决定渗透压的主要溶质体液中起渗透作用的溶质主要是 电解质；Na⁺ 及其伴随阴离子决定细胞外液渗透压 90% 以上
各部分体液渗透压关系各部分体液渗透压基本相等（水可自由通过细胞膜，驱使达平衡）
每日摄入与排出量2000–2500 ml（正常成人出入量平衡）
血容量调节肾素 – 血管紧张素 – 醛固酮系统（RAAS）

1.1 每日水出入平衡（补充）

摄入（约 2000–2500 ml）

饮水 1000–1500 ml

食物含水 700–900 ml

代谢水（内生水） 300 ml

排出（约 2000–2500 ml）

尿 1000–1500 ml

皮肤蒸发 约 500 ml

呼吸蒸发 约 350 ml

粪便 约 150 ml

补临床推论：不显性失水（皮肤蒸发 + 呼吸蒸发约 850 ml）是持续性的、不含电解质的纯水丢失。故 "完全禁食水的患者，每日仍有约 850 ml 的纯水丢失→若不补水，必然发展为高渗性脱水"。气管切开患者呼吸失水可增至 800–1000 ml/d。
渗透压计算

血浆渗透压（mOsm/L）≈ 2 × [Na⁺] + 血糖(mmol/L) + 尿素氮(mmol/L)

简化记忆：渗透压主要由 Na⁺ 及其阴离子贡献，约为血钠值的 2 倍。

临床意义：血糖极高（如高渗高血糖综合征）可显著抬高实测渗透压，造成 渗透性脱水——此时血钠未必升高甚至降低，但渗透压很高。

1.2 体液容量的三大调节系统

① 渗透压调节

感受器：下丘脑渗透压感受器

效应：ADH（抗利尿激素）分泌 + 口渴

→ 调节 晶体渗透压（280–310）

② 容量调节

感受器：容量/压力感受器（心房、颈动脉窦、肾入球小动脉）

效应：RAAS、交感、ANP

→ 调节 血容量 / Na⁺ 总量

③ 肾脏执行

肾是调节水、电解质与酸碱的最终执行器官

每日滤过约 180 L，排出 1.5 L

几乎所有水钠紊乱最终取决于肾功能

关键区分

渗透压感受的是「浓度」，容量感受的是「总量」，二者由不同感受器、不同激素系统分管。

典型考题：低渗性脱水时，渗透压下降抑制 ADH → 早期多尿；但容量下降又刺激 ADH → 晚期少尿。这正是两套系统在「打架」，晚期的容量信号压过了渗透压信号。

补原稿只写了「根据渗透压分类」「根据血钠浓度和溶液量分」两条线索，没有给出完整矩阵。上表即为二维组合的完整展开——9 格，其中带 ★ 的是本章核心考点。
为什么这样分类

这样分类是因为 治疗方向完全不同 且往往相反：

- 低钠血症：核心问题是「水相对过多」→ 限水 / 补钠

- 高钠血症：核心问题是「水相对不足」→ 补水

- 低容量：需补容量

- 高容量：需限水 + 利尿

不同格子，扩容还是限水截然相反，用错方向会直接加重病情

03

三、低容量性低钠血症（低渗性脱水） Hypotonic dehydration

诊断要点数值 / 表现
血浆渗透压< 280 mmol/L
血清 Na⁺< 130 mmol/L
核心机制失钠 > 失水，伴细胞外液量减少
别名低渗性脱水、低容量性低钠血症
订失钠大于失水，扳手细胞外液量减少 → 失钠大于失水，伴细胞外液量减少 — 「扳手」为笔误／识别错误，应为「伴」

3.1 病因与机制

总病因

一句话：任何丢失大量含电解质的体液后，只补充了水而没有补充钠。

这是低渗性脱水区别于其他两种脱水的关键——它是一种 医源性色彩很重 的脱水。

类别具体原因
① 经肾丢失① 长期/大量使用高效（袢）利尿剂（呋塞米）——抑制髓袢升支 Na⁺ 重吸收② 肾功能不全（肾小管重吸收功能障碍）③ 肾上腺皮质功能不全（醛固酮缺乏，Addison 病）④ 渗透性利尿（高血糖、甘露醇）
② 肾外丢失① 严重呕吐、腹泻、胃肠减压、肠瘘（消化液钠含量高）② 大面积烧伤、出血、胸腹水引流③ 大量出汗后只饮淡水
③ 处理不当（关键）上述丢失后 只补水未补钠 → 低渗
这是低渗性脱水最常见的形成路径

3.2 机能代谢变化与临床表现

失钠 > 失水→细胞外液渗透压↓→细胞外液量↓→水自细胞外转入细胞内→细胞水肿 + 细胞外液进一步减少
层次机制与表现
① 细胞外液减少失钠使细胞外液呈低渗，水转入细胞内 → 细胞外液进一步减少（雪上加霜）
▶ 组织间液下降 → 明显 脱水体征（皮肤弹性差、眼窝凹陷、静脉塌陷）
▶ 血容量下降 → 微循环障碍 → 低血容量性休克
② 细胞水肿特别是 脑细胞水肿 → 中枢神经系统功能障碍：嗜睡、淡漠、意识模糊、昏迷、抽搐
③ 无渴感 ★低渗状态下渗透压感受器不被兴奋 → 无口渴
（与高渗性脱水的剧烈口渴形成鲜明对比）
④ 尿量变化 ★早期：多尿（低渗抑制 ADH 分泌）→ 晚期：少尿（容量严重不足，容量感受器压倒渗透压感受器，ADH 大量分泌）
⑤ 尿钠变化 ★经肾失钠者：尿钠升高（>20 mmol/L）
肾外失钠者：尿钠降低（<10 mmol/L）（肾脏代偿性保钠）
这是判断失钠途径的关键指标
临床对比

低渗性脱水 vs 高渗性脱水 的临床表现方向几乎完全相反：

- 低渗：无明显口渴、早期多尿、脱水体征重（组织间液丢得多）、易早期休克

- 高渗：剧烈口渴、少尿、脱水体征轻、晚期才休克

「口渴与否」是床旁最快区分二者的指标

3.3 防治原则

  1. 积极防治原发病（停用利尿剂、纠正肾上腺皮质功能不全等）
  2. 适当补液——纠正细胞外液低渗与容量不足
  3. 原则上给予等渗溶液补液（如 0.9% NaCl、平衡盐溶液）；重症休克者先扩容恢复灌注，必要时辅以少量高渗盐水
补为什么原则上用等渗液？ 因为低渗性脱水患者同时存在 容量不足（低容量） 和 渗透压过低（低钠）。低渗液（如 5% 葡萄糖）进入体内后葡萄糖被代谢，等于补充自由水，会 进一步稀释血钠、加重细胞水肿。因此须用含钠的等渗溶液。
04

四、低容量性高钠血症（高渗性脱水） Hypertonic dehydration

诊断要点数值 / 表现
血浆渗透压> 310 mmol/L
血清 Na⁺> 150 mmol/L
核心机制失水 > 失钠，细胞内、外液均失水
别名高渗性脱水、低容量性高钠血症

4.1 病因

① 水摄入不足

无水可饮：沙漠、海上遇难、水源断绝

不能饮水：昏迷、意识障碍、吞咽困难、婴幼儿

口渴感障碍：下丘脑渗透压感受器受损

禁食水患者 → 忘记补液是医源性常见原因

② 水丢失过多

经肾：尿崩症（中枢性/肾性）、渗透性利尿（高血糖、甘露醇）

经皮肤：高热、大量出汗、烧伤创面蒸发

经呼吸道：过度通气、气管切开

经消化道：呕吐、腹泻（丢失低渗液时失水>失钠）

4.2 机能代谢变化与临床表现

失水 > 失钠→细胞外液渗透压↑→水自细胞内转出→细胞内液减少 = 细胞脱水→各器官因脱水功能障碍
受累系统表现与机制
口渴 ★剧烈口渴（渗透压↑ + 有效循环血量↓ 双重刺激口渴中枢）——最能提示本病
汗腺细胞脱水 ★散热功能障碍 → 脱水热
（尤其婴幼儿与高热患者）
唾液 / 口腔黏膜脱水口舌干燥、口渴难忍
神经细胞脱水 ★脑细胞脱水、脑体积缩小 → 幻觉、躁动、谵妄；可致 脑出血（脑组织牵拉撕裂静脉）
婴幼儿可出现 烦躁、惊厥
肾脏ADH 分泌增多 → 尿少、尿比重高
循环晚期才出现 循环衰竭 / 休克（因细胞内液可外移代偿血容量，故低血容量出现较晚）
为什么口感咋—脱水就发热

这是容易被忽略的一条链：汗腺细胞本身脱水 → 排汗能力下降 → 散热受阻 → 体温升高（脱水热）。

注意区分：「脱水热」不是感染性发热，退烧药无效，补液后才退。儿科尤其常见。

完整链条：失水>失钠 → 细胞外液高渗 → 汗腺细胞脱水 → 出汗减少 → 散热功能下降 → 脱水热。

4.3 防治原则

  1. 防治原发病（控制高热、治疗尿崩症、停用高渗性利尿剂等）
  2. 以补水为主、补钠为辅——首选 5% 葡萄糖溶液 或 低渗（0.45%）盐水
  3. 补液速度不宜过快——过快纠正高钠血症可致 脑水肿（见下方警告）
  4. 适当补钾（纠正过程中钾向细胞内转移，可诱发低钾）
危险警告快速完全纠正高钠血症 → 缓慢纠正，一般血钠下降速度应 ≤ 0.5 mmol/L/h，24 小时内下降幅度 ≤ 10–12 mmol/L — 高渗状态下脑细胞已产生「特发性渗透物」（肌醇、牛磺酸等）以适应高渗；若血钠骤降，细胞外相对低渗 → 水大量进入脑细胞 → 脑水肿、抽搐、昏迷

五、等渗性脱水（原稿完全缺失）★ Isotonic dehydration

重大补缺

原稿最大的结构性遗漏：只讲了低渗性、高渗性脱水，没有「等渗性脱水」。

三类脱水历来作为一组对比考查，且 等渗性脱水是临床上最常见 的一种。此节为完全新增。

项目要点
定义水与钠 成比例丢失，血钠浓度与血浆渗透压 维持在正常范围
血钠135–145 mmol/L（正常）
血浆渗透压280–310 mmol/L（正常）
核心机制丢失的是 等渗液体 → 主要丢失 细胞外液，细胞内液变化不明显
病因① 严重呕吐、腹泻、胃肠减压、肠瘘（最常见）
② 大面积烧伤早期（血浆样液体丢失）
③ 腹膜炎、胰腺炎（大量炎性渗出 accumula 于体腔）
④ 大量胸腔/腹腔积液引流
临床表现兼有脱水与容量不足表现：口渴（较弱）、尿少、皮肤干燥弹性差、血压下降；
不处理可向两头转化：
▶ 若只补水 → 转为 低渗性脱水；
▶ 若不显性失水继续 → 转为 高渗性脱水
治疗补充偏低渗溶液，如 平衡盐溶液、乳酸林格液；或按 2/3 张含钠液补充
（不能只用葡萄糖水，否则转为低渗性脱水）
记性口诀

三类脱水对比（必背）：

- 低渗丢钠多：盐丢得多 → 口渴没有、水体细胞内、早期多尿、早期休克

- 高渗丢水多：水丢得多 → 口渴剧烈、水体细胞外、少尿、脱水热、晚期休克

- 等渗都丢：比例丢、血钠正常、最常见、可两头转化

七、水中毒（高容量性低钠血症） Water intoxication

诊断要点数值 / 表现
核心机制水潴留 >>> 钠潴留（或纯水摄入过多），导致 稀释性低钠血症
血钠< 130 mmol/L
血浆渗透压< 280 mmol/L
体液状态细胞外液 容量增多 且 低渗

7.1 病因

  1. 积极防治原发病
  2. 肾衰、心衰者严格限制水摄入（入水量 = 前日尿量 + 500 ml，这是肾衰补液公式）

② 肾小管重吸收增多近曲小管重吸收水钠增多：

▶ 肾小球滤过分数（FF）增加：出球小动脉收缩程度 > 入球小动脉 → 管周毛细血管胶体渗透压升高、静水压降低 → 近曲小管重吸收增加

远曲小管、集合管重吸收增多：RAAS 激活（醛固酮↑）、ADH↑
③ 有效循环血量减少 ★「有效循环血量减少」是本组机制的触发起点
心衰 / 肾病的共同通路：有效循环血量↓ → 肾灌注↓ → RAAS + ADH 激活 → 水钠潴留 → （但潴留的液体进入组织间隙，血容量并未真正恢复）→ 形成 水肿不断加重的恶性循环
核心理解

为什么心衰患者明明全身水肿，肾脏却仍在保水保钠？

因为肾脏感受的是 有效循环血量，而非总体液量。心衰时心输出量↓ → 肾脏误判为「血量不足」→ 激活 RAAS 拼命保钠保水。

水肿液去了组织间隙，却没有补回有效循环血量 → 保水信号持续存在 → 水肿越来越重。这就是 「充盈不足」学说，也是 利尿剂 + 强心治疗 的理论依据。

8.3 水肿的特点

项目渗出液 vs 漏出液 ★
漏出液（transudate）蛋白含量低（< 25 g/L）、比重低（< 1.015）、细胞数少（< 100 × 10⁶/L）
成因：非炎性——血浆胶体渗透压降低、静水压增高
见于：心衰、肝硬化、肾病综合征
渗出液（exudate）蛋白含量高（> 30 g/L）、比重高（> 1.018）、细胞数多（> 500 × 10⁶/L）
成因：微血管通透性增高（炎症）
见于：感染、肿瘤、结缔组织病
临床意义鉴别漏出液与渗出液是胸腹水诊断的第一步
订正（重要）水肿液的性状：渗出液（毛细血管通透性增高所致 → 炎性水肿）；漏出液（有细胞出现） → 水肿液的性状： 渗出液（微血管通透性↑所致 → 炎性水肿，富含蛋白与细胞）； 漏出液：蛋白与细胞成分均 少（是非炎性滤过液） — 这是知识性错误。漏出液的定义恰恰是「蛋白少、细胞少」，渗出液才是「蛋白多、细胞多」。若按原稿记忆，鉴别诊断会完全反向。
项目特点
水肿皮肤特点皮肤肿胀、弹性差、皱纹变浅/消失；按压出现凹陷 → 凹陷性水肿（显性水肿）
隐性水肿在出现凹陷之前已有组织液增多，体重增加可达原体重的 10%（原稿数值正确）
临床提示：每日测体重是发现隐性水肿最灵敏的方法
全身性水肿分布特点 ★▶ 肾性水肿：从颜面部（眼睑）开始，发展迅速，肿处 软而移动度大（颜面部结缔组织疏松）
▶ 心性水肿：从双下肢足踝向上发展，与重力相关，发展较迅速，移动度小
▶ 肝性水肿：以 腹水 为主要表现，发展速度慢

8.4 水肿对机体的影响

✅ 有利方面

炎性水肿 可以：

① 稀释毒素

② 运送抗体、补体、药物至病灶

③ 其中的纤维蛋白可限制病原扩散

九、钾的正常代谢 Potassium homeostasis

9.1 钾的生理功能

  • 维持细胞新陈代谢：参与 糖原合成、蛋白质合成（钾是多种酶的辅因子）
  • 保持静息膜电位，参与动作电位形成 → 支配神经肌肉与心肌的电活动
  • 调节渗透压与酸碱平衡（与细胞外 H⁺ 交换）

9.2 钾的平衡

环节要点
摄入食物 50–120 mmol/d（约合氯化钾 3–6 g/d）

体内总含钾量 50–55 mmol/kg 体重（成人约 150 g）

- 术后、昏迷、肠梗阻患者若只补葡萄糖盐水 而不补钾，必然在数日内出现低钾血症。

- 静脉输注大量含糖液体还会 刺激胰岛素分泌 → 钾向细胞内转移，雪上加霜。

这是外科术后最常见的电解质失衡之一。

9.3 钾平衡的调节

（一）跨细胞转移——泵-漏机制

机制说明
泵Na⁺-K⁺ 泵（Na⁺-K⁺-ATP 酶）：消耗 ATP，将 K⁺ 泵入细胞内、Na⁺ 泵出
漏K⁺ 顺浓度差经 各种 K⁺ 通道 漏出细胞
净效应泵与漏的动态平衡，精确地维持 细胞外液的钾浓度
这是 快速调节（数分钟至数小时）
影响因素对钾跨细胞转移的作用
胰岛素 ★促进 K⁺ 进入细胞（激活 Na⁺-K⁺-ATP 酶）
临床：用胰岛素+葡萄糖治疗高钾血症
儿茶酚胺（β₂ 激动）促进 K⁺ 进入细胞（β₂ 受体阻断剂则相反）
细胞外液 K⁺ 浓度升高时促进泵摄取
酸碱平衡 ★H⁺-K⁺ 交换：酸中毒 → H⁺ 入细胞、K⁺ 出细胞 → 血钾升高；碱中毒则相反 → 血钾降低
血浆渗透压升高（如高血糖）→ 水移出细胞、K⁺ 随之移出 → 血钾升高
运动 / 组织分解肌肉活动释放 K⁺；大量溶血、挤压伤、肿瘤溶解释放 K⁺

（二）肾对钾排泄的调节

肾小球滤过的钾 90%–95% 已在近曲小管与髓袢重吸收。尿钾的多少主要取决于 远曲小管、集合管的分泌（主细胞分泌 K⁺，闰细胞重吸收 K⁺）。

影响因素作用
① 醛固酮 ★保钠排钾——最重要的调节激素
促进远曲小管/集合管主细胞重吸收 Na⁺、分泌 K⁺
② 细胞外液 K⁺ 浓度升高 → 直接刺激醛固酮分泌 + 直接促进集合管泌钾
③ 远端原尿流速 ★流速加快 促进排钾
机制：冲刷掉小管腔内堆积的 K⁺，维持浓度梯度
临床：袢利尿剂/噻嗪类 → 流速↑ → 排钾增多 → 低钾血症
④ 酸碱平衡状态酸中毒 抑制排钾（H⁺ 与 K⁺ 竞争分泌）；碱中毒 促进排钾
补

为什么「远端原尿流速」是重要的？ 这解释了许多临床现象：

- 利尿剂致低钾：不只是醛固酮的作用，流速加快本身就是强力的排钾因素。

- 容量不足时 近端重吸收增加 → 到达远端的液体少 → 远端流速慢 → 排钾减少。

- 这是理解「低钾血症为什么常伴随呕吐腹泻/利尿」的关键机制环节。

9.4 钾代谢紊乱的分类

① 细胞内钾异常

细胞内钾过多：一般无明显影响

细胞内钾缺乏：导致代谢障碍

⚠️ 可发生在血清钾正常时——总钾亏空未必表现为低钾血症

② 血清钾异常 ★

低钾血症：血清钾 < 3.5 mmol/L

高钾血症：血清钾 > 5.5 mmol/L

正常血清钾：3.5–5.5 mmol/L

血清钾 ≠ 总钾

血清钾只占体内总钾的 2%，是一个「快照」而非「库存」指标。

- 缺钾时，细胞内钾先外移代偿 → 血清钾可正常（隐性缺钾）

- 反之，酸中毒（K⁺ 外移）时 血清钾可升高，但总钾可能亏空

临床推论：判断体内是否真正缺钾，需结合 摄入史、丢失途径、尿钾、血气分析，而不能只看一次血清钾。

收缩性↓（严重时心肌收缩无力）
心电图 ★特征：T 波低平或倒置、ST 段压低、U 波增高（有时 U 波 > T 波）、Q-U 间期延长
（注意：低钾延长的是 Q-U 而非真正的 Q-T）
心律失常期前收缩、心动过速；严重 → 心室颤动
低钾时心肌对洋地黄（地高辛）的敏感性显著增加，极易发生洋地黄中毒
为什么低钾时心肌与骨骼肌表现相反

骨骼肌：超极化阻滞 → 兴奋性↓ → 软瘫。

心肌：低钾使心肌膜对 K⁺ 通透性降低 → K⁺ 外流减少 → 静息电位负值减小（更接近阈电位）→ 兴奋性与自律性↑。

这是理解「低钾患者既瘫痪又心律失常」的关键——同一血钾值，不同组织走不同的电生理途径。

（三）肾损害与酸碱失衡 ★

后果机制与表现
肾浓缩功能障碍集合管上皮受损 → 多尿、夜尿增多、低比重尿
长期可致 缺钾性肾病（肾小管空泡变性）
代谢性碱中毒 ★双向机制：
① 细胞内 K⁺ 外移、细胞外 H⁺ 内移 → 细胞外 H⁺ 减少 → 碱中毒
② 肾小管 K⁺-Na⁺ 交换减少、H⁺-Na⁺ 交换增多 → H⁺ 排出增多 → 加重碱中毒
反常性酸性尿 ★★★低钾 → 代谢性碱中毒，但 尿却呈酸性
机制：肾小管为保 Na⁺ 而优先排 H⁺（因缺 K⁺ 无法进行 K⁺-Na⁺ 交换）

这是区别于其他碱中毒（尿应碱性）的 标志性特征，也是经典考点

10.3 补钾原则（★必背）

① 途径

首选口服（氯化钾口服液 / 缓释片），安全、经济

严重或无法口服才 静脉补钾

治疗原发病 是根本（停利尿剂、纠腹泻等）

② 静脉补钾五原则 ★

1. 见尿补钾：尿量 > 40 ml/h 才可补

2. 浓度不过高：一般 ≤ 0.3%（即 ≤ 40 mmol/L）

3. 速度不过快： ≤ 10–20 mmol/h

4. 剂量不过大：每日 3–6 g KCl（严重可适当增加，需监测）

5. 禁止静脉推注（可致心脏骤停）

危险警告静脉推注氯化钾快速纠正低钾 → 必须稀释后缓慢静脉滴注，严禁直接静脉推注 — 钾离子直接注入可瞬间造成心肌传导阻滞、心搏骤停，属于绝对禁忌

十一、高钾血症（原稿完全缺失）★ Hyperkalemia

重大补缺原稿完全未涉及高钾血症。 尽管课时占比不如低钾，但高钾的 致死性最强（心跳骤停），是急诊必争项，务必掌握。
项目要点
定义血清钾 > 5.5 mmol/L
危险性高钾血症最主要的危害是 心脏毒性，可致 心室颤动 / 心跳骤停

11.1 原因与机制

① 摄入过多

静脉补钾过多过快（违反上述原则）

输入大量库存血（库存血随时间延长红细胞内钾外漏，2 周血钾可达 15–20 mmol/L）

⚠️ 肾功能正常者单纯口服极少致高钾

② 排出减少（最常见）

急 / 慢性肾衰竭（特别是少尿、无尿）← 临床上最常见的原因

醛固酮缺乏：Addison 病、低肾素低醛固酮血症

保钾利尿剂：螺内酯、氨苯蝶啶；ACEI / ARB

（与钾剂合用、用于肾功不全者极危险）

③ 细胞内钾外移

酸中毒（H⁺ 入细胞、K⁺ 出细胞）

胰岛素缺乏（DKA 时血钾常很高，尽管总钾亏空）

大量溶血、挤压伤、烧伤、肿瘤溶解综合征

β 受体阻滞剂、洋地黄中毒（抑制 Na⁺-K⁺ 泵）

高钾型周期性麻痹

④ 假性高钾（注意）

采血时溶血、标本放置过久、血小板显著增多（体外释放钾）

遇到「高钾」但无心电图改变、无临床症状时，首先怀疑假性高钾，复查

11.2 对机体的影响

（一）神经肌肉

程度表现与机制
轻度（5.5–7 mmol/L）静息电位负值 减小 → 更接近阈电位 → 兴奋性↑
表现：手足感觉异常、肢体刺痛、肌肉震颤、乏力
重度（> 7 mmol/L）静息电位过小 → Na⁺ 通道失活 → 去极化阻滞 → 兴奋性↓
表现：肌无力、弛缓性瘫痪（由下肢向上发展，可累及呼吸肌）

（二）心肌——最危险 ★

项目变化
兴奋性轻度时↑，重度时↓
传导性↓（PR 延长、QRS 增宽）
自律性↓
收缩性↓
心电图演变 ★T 波高尖（呈「帐篷样」T 波） ← 最早出现
→ P-R 间期延长、P 波低平或消失
→ QRS 波群增宽
→ 严重时出现 正弦波（QRS 与 T 融合）
→ → 心室颤动 / 心搏骤停

（三）酸碱失衡

与低钾方向完全相反

高钾血症 → 代谢性酸中毒 + 反常性碱性尿

- 机制：细胞外 K⁺ ↑ → K⁺ 入细胞、H⁺ 出细胞 → 细胞外 H⁺ ↑ → 酸中毒

- 肾小管：K⁺-Na⁺ 交换↑、H⁺-Na⁺ 交换↓ → H⁺ 排出减少

- 故尽管血呈酸性，尿却呈碱性

对照记忆：

- 低钾 → 碱中毒 + 酸性尿

- 高钾 → 酸中毒 + 碱性尿

11.3 急救处理（★急诊必考）

处理指征血清钾 > 6.5 mmol/L，或出现任何心电图改变（尤其 T 波高尖），应立即启动紧急处理。
顺序措施要点
1 ★静脉钙剂10% 葡萄糖酸钙 10–20 ml 缓慢静推（数分钟起效）
作用：稳定心肌细胞膜、对抗钾的心脏毒性；但它并不降低血钾
这是 最关键的第一步，先保命
2胰岛素 + 葡萄糖10% GS 500 ml + 普通胰岛素 12 U（或 25% GS 40 ml + 胰岛素 6 U）静滴
促进 K⁺ 进入细胞，约 30 min 起效，持续 4–6 h
3碳酸氢钠5% NaHCO₃ 或者 11.2%乳酸钠静滴
碱化血液 → 促 K⁺ 入细胞；尤适用于伴酸中毒者
4β₂ 受体激动剂沙丁胺醇雾化吸入（10–20 mg）促 K⁺ 入细胞
5阳离子交换树脂聚磺苯乙烯（Kayexalate）口服或灌肠——将钾从肠道排出（起效慢）
6 ★透析血液透析 / 腹膜透析 是最有效、最根本的手段
适用于肾衰竭、上述措施无效者
辅助停用钾源立即停用钾剂、保钾利尿剂、ACEI/ARB；控制含钾食物与药物
为什么先给钙

钙剂不降钾，但能保命。

高钾的致命危险在于心肌 —— 钙离子提高阈电位（恢复静息电位与阈电位的正常差距），直接对抗钾对心肌的毒性，起效 数分钟内。

而胰岛素、碳酸氢钠等措施降低血钾需要 30 min 以上。因此在等待「降钾」起效前，必须先用钙剂「护心」。

处理顺序具有强制性：先稳膜（钙），再降钾（胰岛素/碱性/利尿/透析）。

十二、低钾 vs 高钾 终极对比 Potassium comparison

对比项低钾血症高钾血症
血清钾< 3.5 mmol/L> 5.5 mmol/L
神经肌肉 ★兴奋性↓ → 弛缓性瘫痪（软瘫）
腹胀、麻痹性肠梗阻、反射减弱		轻度兴奋性↑（感觉异常、震颤）

心肌兴奋性↑轻度↑，重度↓

致命后果心室颤动、呼吸肌麻痹心室颤动 / 心搏骤停（更危急）
酸碱失衡 ★代谢性碱中毒代谢性酸中毒
尿液酸碱性 ★反常性酸性尿反常性碱性尿
心肌对洋地黄敏感性↑，易中毒——
治疗核心补钾（口服优先；静滴见尿补钾、禁推注）先 钙剂稳膜，再胰岛素+糖 / 碱剂 / 利尿 / 透析
反常性尿记忆法

「低钾碱中毒、酸性尿；高钾酸中毒、碱性尿」

记忆关键：血的变化与尿的变化方向永远相反 —— 因为肾小管在 K⁺ 与 H⁺ 之间进行的是 竞争性交换（K⁺-Na⁺ vs H⁺-Na⁺）。

- 低钾 → 无法排 K⁺ → 只能多排 H⁺ → 尿变酸、血变碱

- 高钾 → 大量排 K⁺ → H⁺ 排出少 → 尿变碱、血变酸

十三、考点速记 Key points

13.1 必背数值

渗透压与水量

血浆渗透压 280–310 mmol/L

每日出入量 2000–2500 ml

不显性失水 约 850 ml

血钠

正常 135–145 mmol/L

低钠 < 135；低渗性脱水 < 130

高钠 > 145；高渗性脱水 > 150

血钾

正常 3.5–5.5 mmol/L

低钾 < 3.5；高钾 > 5.5

急诊降钾指征 > 6.5

钾的分布与排泄

总钾 50–55 mmol/kg

细胞内 约 98%，血清仅约 2%

摄入 50–120 mmol/d

排泄：肾 80–90%、肠 10%

水肿

隐性水肿体重增加可达 10%

漏出液蛋白 < 25 g/L、细胞 < 100×10⁶/L

渗出液蛋白 > 30 g/L、细胞 > 500×10⁶/L

纠正速度

低钠纠正 ≤ 4–8 mmol/L/24h

高钠纠正 ≤ 10–12 mmol/L/24h

13.2 一句话鉴别

  • 是否口渴：有口渴 → 高渗性 / 等渗性；无口渴 → 低渗性
  • 休克早晚：早休克 → 低渗性；晚休克 → 高渗性
  • 尿量早晚：早多尿晚少尿 → 低渗性（两套感受器打架的结果）
  • 补液选择：低钠补 等渗；高钠补 低渗/糖水；等钠补 平衡盐
  • 心电图：U 波增高 → 低钾；T 波高尖 → 高钾
  • 尿液：低钾 酸性尿（伴碱中毒）；高钾 碱性尿（伴酸中毒）
  • 水肿起始部位：眼睑开始 → 肾性；足踝向上 → 心性；腹水为主 → 肝性

13.3 水肿机制五问自查

① 毛细血管流体静压↑？（心衰、静脉阻塞）→② 血浆胶体渗透压↓？（肝病、肾病、营养不良）→③ 微血管通透性↑？（炎症、过敏、烧伤）→④ 淋巴回流受阻？（丝虫病、肿瘤压迫）→⑤ 肾水钠潴留？（GFR↓ / RAAS↑ / ANP↓）

学习方法建议

本章的最佳切入点是 「血钠定类型、容量定程度」 与 「先-EKG 后-补液」 两条主线。

建议顺序：

1. 先背 三个脱水的核心数值（130 / 150 / 正常），建立骨架；

2. 再用 「口渴 — 休克早晚 — 尿量」 三指标做床旁鉴别；

3. 钾的部分单独攻 —— 重点抓 心电图 与 反常性尿 两组对应；

4. 最后统一刷 治疗/补液选择，这是区分高分与及格的分水岭。
